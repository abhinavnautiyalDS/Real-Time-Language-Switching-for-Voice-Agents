MODEL NOTES / IMPLEMENTATION

A small model
with a focused job.

This page documents the classifier behind the interactive demo: where it sits in a voice pipeline, what it predicts, and how to interpret its output.

MODEL: BERT-TINY E4INFERENCE: CPUOUTPUT: 11 LANGUAGE LABELS + OTHER FALLBACK
01 / PIPELINE POSITION

From speech to a language tag.

The classifier consumes text produced by STT. It does not process raw audio and it does not generate the final response.

01SpeechCaller audio
→
02STTTranscript text
→
03Language IDBERT-Tiny classifier
→
04Reasoning LLMTranscript + language tag
→
05TTSSpoken response

This is the proposed integration pattern. The hosted page demonstrates the standalone classifier API; it does not claim that the complete voice-agent pipeline is deployed here.

02 / MODEL PROFILE

Compact by design.

04 / READING THE RESPONSE

What the API returns.

The demo displays the prediction and the measurements returned by the inference service. Values are not fabricated in the browser.

prediction

Language and code

The highest-scoring predicted label, represented by a language name and its label code.

score

Softmax score

A model score expressed as a percentage. It is not a calibrated probability or a guarantee of correctness.

inference_ms

Measured inference time

The inference duration reported by the API for that request. It is not a full end-to-end voice response time.

alternatives

Other model scores

Additional ranked label scores returned by the classifier, when available.

05 / SCOPE & LIMITATIONS

A focused component, not the whole voice agent.

  • Input is transcript text; speech recognition is outside this demo.
  • Classification is performed for the current input text, not from a multi-turn conversation history.
  • Softmax scores are not calibrated confidence estimates.
  • Performance depends on the checkpoint, script, spelling, code-switching pattern and input length.
  • The page does not claim guaranteed same-turn language switching or production voice-agent integration.
