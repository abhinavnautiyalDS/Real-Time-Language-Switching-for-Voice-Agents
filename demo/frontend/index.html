THE REASON IT EXISTS

One small signal.
One better-timed response.

Language identification belongs close to the transcript—not buried inside a slower reasoning step.

THE PROBLEM / 01

Language switches can be missed in the moment.

When a voice agent relies on its reasoning model to infer every language change, that work adds to the response path. The agent may continue in the previous language for another turn.

THE APPROACH / 02

Classify the current transcript first.

A compact classifier predicts a language tag immediately after speech-to-text. That signal can be passed to the reasoning model with the transcript and context.

THE PROPOSED FLOW / 03
Speech→STT→Language ID→Reasoning LLM→TTS

Standalone classifier demo. End-to-end voice-agent integration is a separate engineering step.
