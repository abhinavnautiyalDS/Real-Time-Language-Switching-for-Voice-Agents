WHY THIS EXISTS

A small step in the pipeline.

The goal is not to replace the language model. It is to identify the current turn's language before the reasoning model responds.

01 — THE PROBLEM

Language switching could arrive a turn late.

In a multilingual voice-agent flow, language identification was being left to a large Gemma model. That added work to the response path and could make the agent continue in the previous language after a caller switched.

02 — THE APPROACH

Classify the transcript immediately after STT.

A fine-tuned BERT-Tiny classifier predicts a language tag from the current transcript. The tag can then be passed to the reasoning model alongside the transcript and conversation context.
